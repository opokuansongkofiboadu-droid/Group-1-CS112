# ClinicCare-Lite User Guide

## 1. Introduction

ClinicCare-Lite is a clinic administration and communication system for patients and clinicians.

It allows clinicians to assign tasks, review submissions, create appointments and announcements, and communicate with patients.

Patients can view assigned tasks, upload files, receive feedback, view appointments and announcements, and communicate with clinicians.

ClinicCare-Lite is not a diagnostic system and should not be used for medical emergencies.

---

# Patient Guide

## 3. Patient Dashboard

After logging in as a patient, the dashboard shows:

- Assigned tasks
- Task due dates
- Submission status
- Clinician feedback
- Messages
- Appointments
- Clinic announcements
- Engagement points

Patients can also change between the colorful and dark themes.

---

## 4. Submitting a Task

To submit a task:

1. Log in as a patient.
2. Find the assigned task on the dashboard.
3. Click the file upload option.
4. Select the required file.
5. Submit the file.

ClinicCare-Lite accepts:

- TXT
- CSV
- PDF

Files larger than 5 MB or unsupported file types will be rejected.

After submitting, the task status changes to show that the submission has been received.

---

## 5. Viewing Clinician Feedback

After the clinician reviews a submission, the patient can view:

- Review outcome
- Clinician notes
- Updated task status

The patient will also receive an in-app notification.

---

## 6. Messaging a Clinician

Patients can use the messaging section to send non-urgent messages to a clinician.

Messages should not be used for emergencies because the inbox is not continuously monitored.

---

## 7. Viewing Appointments and Announcements

Appointments created by the clinician appear on the patient dashboard.

Clinic announcements also appear on the patient dashboard so that patients can see important administrative information.

---

# Clinician Guide

## 8. Clinician Dashboard

After logging in as a clinician, the dashboard provides access to:

- Task creation
- Patient submissions
- Submission review
- Messaging
- Appointments
- Announcements
- Basic analytics

---

## 9. Creating a Task

To assign a task:

1. Log in as a clinician.
2. Go to the task creation section.
3. Enter the patient's ID.
4. Enter the task title.
5. Add instructions or a description.
6. Select a due date.
7. Create the task.

The task will then appear on the patient's dashboard.

---

## 10. Reviewing a Submission

When a patient submits a file:

1. Open the clinician dashboard.
2. Find the patient submission.
3. Download the file if necessary.
4. Select a review outcome.
5. Enter review notes.
6. Submit the review.

The patient will then be able to see the outcome and notes.

The patient will also receive an in-app notification.

---

## 11. Creating an Appointment

Clinicians can create appointments by entering:

- Patient ID
- Date
- Time
- Purpose

The appointment will appear on the patient's dashboard.

---

## 12. Creating an Announcement

Clinicians can create clinic announcements from the clinician dashboard.

The announcement will then appear on patient dashboards.

---

## 13. Messaging Patients

Clinicians can read messages sent by patients and send replies through the inbox.

The messaging feature is intended only for non-urgent communication.

---

## 14. Analytics

The clinician dashboard displays basic operational information such as:

- Total tasks
- Total submissions
- Reviewed submissions
- Pending reviews
- Completion rate

These statistics are administrative and do not provide medical diagnoses.

---

## 15. Logging Out

When finished using ClinicCare-Lite, click **Logout**.

Users should always log out when using a shared computer.

---

## Important Notice

ClinicCare-Lite is an academic prototype.

It does not diagnose illnesses, interpret symptoms, recommend treatment, prescribe medication, or replace professional clinical judgement.

For emergencies or urgent medical concerns, users should contact the appropriate healthcare or emergency service.
